## 🚀 About This Project

This repository contains the source code for my personal portfolio. Designed from scratch, it serves as a digital resume and a showcase of my technical skills, creative projects, and professional journey. It is fully responsive, interactive, and optimized for performance.

> **Fun Fact:** This entire site is built using pure vanilla web technologies—no heavy frameworks, just clean, semantic code.

## ✨ Key Highlights

* **🎨 Custom UI/UX:** A unique, aesthetically pleasing design utilizing modern CSS Grid and Flexbox layouts.
* **📱 Fully Responsive:** Carefully crafted media queries ensure a flawless experience across mobile, tablet, and desktop screens.
* **⚡ Interactive DOM:** Smooth scrolling, active navigation states, and dynamic elements powered by vanilla JavaScript.
* **🖼️ Optimized Assets:** Utilizes organized asset management via dedicated `images2/` and `ss/` directories.
* **🌐 Automated Deployment:** Seamlessly hosted and continuously integrated using GitHub Pages.
